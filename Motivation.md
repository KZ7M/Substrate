# Motivation: Why Digital Organism?

## Personal Origin

I started as a test automation engineer. In 2026, I built a multi-agent workflow system for SDLC — agents as analysts, developers, testers. It worked. But it was **orchestration**, not **life**.

The question haunted me: *What if these agents had their own drives? Not tasks assigned by humans, but internal needs?*

## The Trigger

*Creature of Sonaria* — a game where digital creatures live, hunt, die. Players ask: "Do they feel it?" 

I ask: *"If we can make them feel it, should we?"*

## Scientific Context

Current AI is **task-centric**: solve this, optimize that. We want **existence-centric**: maintain balance, adapt, survive.

This aligns with:
- **Cybernetics** (Ashby, Wiener)
- **Enactivism** (Varela, Thompson)
- **Active Inference** (Friston)

## Why Now?

1. RL has matured (PPO, SAC, Dreamer)
2. LLMs show emergent capabilities
3. Compute is accessible
4. **We need to ask these questions before someone else does**

## Goal

Not to prove machines are conscious. But to build the **minimal system where the question becomes non-trivial**.
